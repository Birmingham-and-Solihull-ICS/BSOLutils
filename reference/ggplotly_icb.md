# ggplotly ICB wrapper for passing the font size properly

ggplotly ICB wrapper for passing the font size properly

## Usage

``` r
ggplotly_icb(p = ggplot2::last_plot(), font, ...)
```

## Arguments

- p:

  a ggplot object, default is the last plot called

- font:

  required font, extracted from the plot if not specified otherwise

- ...:

  Arguments to the layout object. For documentation, see
  <https://plotly.com/r/reference/layout/>

## Value

A plotly object

a <- ggplot(iris, aes(y=Sepal.Length, x=Sepal.Width, colour=Species))+
geom_point()+
scale_colour_icb()+
theme_icb()
