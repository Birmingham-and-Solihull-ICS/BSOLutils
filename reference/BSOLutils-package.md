# BSOLutils: Utilities and general helper R package with various functions

This package contains numerous helper functions. There include functions
for confidence intervals, predicting SQL data types, ggplot themes and
palettes, ploty helpers, binomial thinning, standardisation methods and
dispersion metrics.
