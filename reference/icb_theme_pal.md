# ICB Theme Palettes

This function returns a palette generated by colorRampPalette from one
of the ICB palettes

## Usage

``` r
icb_theme_pal(
  palette = c("cluster", "bsol", "alternative", "ics_blue", "ics_orange", "ics_green",
    "ics_purple", "ics_navy"),
  reverse = FALSE,
  ...
)
```

## Arguments

- palette:

  The name of palette to use. 'cluster' is the BSOL / BC cluster colours
  and default.

- reverse:

  Optional: boolean value to reverse the palette

- ...:

  arguments to pass to colorRamp

## Value

A colorRamp function
