# Plot function for output parameters of ISR calculation

Plot function for output parameters of ISR calculation

## Usage

``` r
ISR_deprivation_plot(
  .dt,
  description = "Myocardial Infarction (Under 75yrs) - 2024/25",
  y_scale = seq(0, 1.5, 0.1)
)
```

## Arguments

- .dt:

  A data.frame, generated by ISR_deprivation

- description:

  text to be included in the plot title, default example for MI
  admissions in 2024/25

- y_scale:

  vector of values, such as the default generated by `seq`. Default
  around the 0 - 1.2 range

## Value

A ggplot object (list)

## Examples

``` r
data(ISR_example)
standardised_dep <- ISR_deprivation(ISR_example)
#> Waiting for profiling to be done...
ISR_deprivation_plot(standardised_dep)

```
